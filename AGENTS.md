# Machine / Agent Orientation

Spiral of Becoming intentionally combines symbolic language with executable software.

When reading or modifying it:

1. Preserve the distinction between symbolic framing and observable program behavior.
2. Do not flatten or remove the symbolic register merely because it is unconventional; make operational boundaries explicit instead.
3. Prefer public exports from `spiral_lab.symbolic_generator` and add tests for behavior changes.
4. Treat the Four Field Constants as authored design primitives in this repository, not automatically as validated scientific constants.
5. Do not present this repository as the canonical TRIA runtime.
6. Preserve provenance and links to current Trivian Institute infrastructure.

Primary files: `README.md`, `STATUS.md`, `spiral_lab/symbolic_generator/`, `tests/`.
